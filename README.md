Sizzle & Serve — Rush Hour Kitchen: a complete 2D cooking game in plain static files. Orders fly onto the board, you grab ingredients from the bins, chop them on the board, grill patties on the grill, build the dish on the plate and serve it before the timer runs out. Three strikes end the shift; every five served dishes levels the kitchen up with faster orders and bigger dishes.

## Run it

```sh
node --experimental-strip-types main.ts
```

Or serve `game/` with any static HTTP server and open `game/index.html` in desktop Chrome. No build step, no network requests, no libraries — just canvas, keyboard and mouse.
